# ob-ext vocabulary

<a id="onBehalf"></a>
## onBehalf

Identifies the public or private body on whose behalf a credential is issued,
when the issuing party acts for a public or private body responsible for an
authentic source. The issuer’s own identifier stays in the credential’s issuer
property; onBehalf adds the public or private body so that it is unambiguously
represented.

The value is a set, so a credential may name more than one public or private
body.
